# Patterns from the field research

Numbering used by all three personas. Quotes are copied from `research/field_notes.md`.

| # | Pattern | Verbatim | Job to be done | Insight |
|---|---|---|---|---|
| P1 | The wait starts the calls; the lack of news makes them repeat | Julio21: «llamo por teléfono día sí y día no [...] siempre me dicen lo mismo»; Toni: «están constantemente comunicándose con nosotros» | Functional: know where my file is, what is missing and what comes next | People call to find out if their wait is still normal. A call that brings "the same" answer tells them nothing, so they call again. |
| P2 | Nobody owns the file, so the user becomes its manager | pantaleon: «la comercializadora me dice que la distribuidora rechaza [...] y la distribuidora que la comercializadora»; PUMA: «se desentiende de este tema» | Functional: get my file moving without coordinating it myself | Each party answers for one piece and sends the user to the other. Only the user follows the whole file. |
| P3 | Errors from every side appear only after the file is sent | Tevi62: «la cuarta que los mandan, vuelven a estar rechazados»; Toni: «el cliente se olvida de que tiene que firmar unos papeles» | Functional: have the file accepted the first time | Each rejection restarts the wait, and a small reason costs a long delay. |
| P4 | Trust travels from person to person | N. M.: «Muchas felicidades Marc»; Toni: «por contactos y recomendaciones» | Emotional (social): look good before the people I recommend an installer to. Emotional (personal): feel that someone I know is responsible for my case | Clients come because someone vouched for Voltia, and a happy client thanks a person by name. |
| P5 | Finished work that cannot be used feels unfair | Julio21: «está todo perfectamente realizado y no puedo tener luz por este trámite»; Tevi62: «impotencia» | Emotional (personal): get my normal life back and stop feeling powerless | Once the work is done, the wait looks like a decision against the user. |

## Where each pattern is strongest on the line

- Hard end: P2, P3, P5 (and P1 as a routine).
- Easy end: P4 (and P1 in a small, calm form).
- Regular: P1 (the call that asks "is this normal?"), with P3 and P4 as risks.
