# Report: three personas for the Voltia challenge

Challenge: Voltia clients with an Iberdrola (i-DE) file or an electrical certificate in progress do not know what is happening with it.

## Personas and checker verdicts

| Persona | Point of the line | Checker verdict | Tries | Words |
|---|---|---|---|---|
| persona-1-hard-end (Julio*) | Very slow or blocked file | PASS | 1 | 435 |
| persona-2-easy-end (Nuria*) | Follows many files with ease | PASS | 1 | 471 |
| persona-3-regular (Carmen*) | Normal file | PASS | 1 | 452 |

Nothing is still failing. Two honest limits: persona 2 joins a happy Voltia client (N. M.) with an expert who manages 15 files (Herrera), whose files were slow. Persona 3 has no direct voice in the research, so it is mostly inferred and carries many asterisks.

## What the three share (common jobs to be done)
- **Functional:** know where my file is, what is missing and what comes next (P1).
- **Functional:** have the file accepted the first time (P3).
- **Emotional:** feel safe because I know one person by name, and keep my word to the people I answer to (P4).

All three also live with a process that nobody owns for them (P2).

## What changes from one end of the line to the other
- **Hard end:** the wait is long and the work is finished, so the feeling moves from "when?" to "can I report them?" and helplessness (P5). He manages the file himself, for hours (P2). He calls often and gets "the same" (P1).
- **Regular:** the file is not in crisis. The need is to know if the wait is normal, and delays can start in the job itself (P1, P3).
- **Easy end:** trust sits in a known person and a kept promise (P4). The need is less about calling and more about knowing each file is on track, though the same process limits still apply (P2, P3).
- Across the line, P5 grows with the wait, and P4 holds or breaks the trust.

## Which persona to design for first
The team should start with persona 1, the hard end. It is the only persona built from real quotes, and it shows all five patterns in their strongest form. The cost of silence is highest there: hours of calls, a home without power, and trust in a person lost. Persona 3 is the likely majority but rests on inference, so it should be checked against real clients afterwards.
